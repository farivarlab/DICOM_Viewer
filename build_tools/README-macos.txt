Lumen DICOM Viewer - macOS

Not For Diagnostic Use. Research and education software.

Install with Homebrew:
    brew install --cask farivarlab/lumen/lumen

Or drag Lumen.app from this archive into Applications.

This build is not signed with an Apple Developer ID or notarized. The first time you
open it, macOS may say it cannot verify the developer. Open System Settings > Privacy
& Security, find the message about Lumen and choose Open Anyway. You only need to do
this once.

Preferences and saved annotations are stored in
~/Library/Application Support/Lumen DICOM. All image processing is local; input files
are opened read only. No example patient studies are included.

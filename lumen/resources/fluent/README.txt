This directory contains a small subset of the regular 20-pixel SVG icons.
manifest.json records each source path and the SHA-256 of its unchanged SVG.
Lumen recolors the SVGs in memory for the selected UI theme.
The specialist imaging-tool glyphs in lumen/icons.py are original artwork.
No Windows icon fonts or extracted operating-system resources are bundled.
